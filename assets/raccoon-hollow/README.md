# Raccoon Hollow artwork

`icon.png` is the original transparent pixel-art raccoon with headphones created
for this appearance. The native window consumes this asset only when the
Raccoon Hollow profile is selected. Desktop launchers manage their own icon.
The small shell mascot is drawn as an original pixel sprite in `src/ui/raccoon.rs`.

Pixelify Sans is bundled separately under its SIL Open Font License in
`assets/fonts/PixelifySans-LICENSE.txt`. Existing fonts remain as language and
emoji fallbacks.
